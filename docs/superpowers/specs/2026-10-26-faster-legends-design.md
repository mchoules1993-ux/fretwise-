# Faster Legends studies

The owner chose five new faster licks, one for each existing legend, with tabs,
technique tips, audio and the existing slower practice speeds. This adds musical
variety and a higher practice target while retaining the five current studies.

## Approaches

- Chosen: one additional original study each for SRV, Hendrix, Page, Clapton and
  Moore. This covers every player at the cost of five new phrases to validate.
- Alternative: three studies covering fast shuffle, triplets and sixteenths.
  Smaller, but leaves some players without a faster study.

## Design

Append five original two-bar A-based technique studies at 112–140 BPM to
`LEGEND_LICKS`, preserving the existing indices and shared player. Each has a
distinct rhythmic/technical focus, full mobile and wide tablature, count-in,
matched A7 or A-minor accompaniment, loop support and WAV download. Reuse the
60/75/100% speed controls; faster phrases remain learnable slowly without
changing pitch. Label the new studies as fast and update the displayed total,
credits and release catalogue. These are original exercises inspired by general
techniques, never claimed as artist recordings or song transcriptions.

No new dependencies, audio assets, Jam Room tempo changes or publishing work.
Implementation choices: append the five studies after the existing five; use
112, 116, 120, 128 and 140 BPM; retain existing song-study reference links as
separate learning resources. Verify phrase bounds, tab output, effective tempo,
playback, stopping and WAV export alongside both repository regression checks.
